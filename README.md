### ⚙️ PRACTICE / 工作重点

- **算法闭环 / Algorithm loop** — 从任务与目标指标出发，建立可比较的基线，再通过数据、模型和误差分析定位效果瓶颈。 / Start from the task and target metrics, establish a comparable baseline, then use data, model, and error analysis to locate bottlenecks.
- **应用链路 / Application flow** — 把检索、上下文、工具调用和结果校验组织成可追踪的多步流程。 / Assemble retrieval, context, tool calls, and output checks into a traceable multi-step workflow.
- **评测与迭代 / Evaluation** — 优先使用明确、可复现的任务检查；对主观质量、延迟、成本和稳定性分别观察。 / Prefer explicit, reproducible task checks; track subjective quality, latency, cost, and reliability separately.
- **故障定位 / Error analysis** — 区分数据、算法/模型、检索、工具和流程编排层的问题，再针对瓶颈调整方案。 / Separate issues in data, models, retrieval, tools, and orchestration before changing the approach.

### 🔁 ENGINEERING LOOP / 工程闭环

```text
Understand the task → Choose an approach → Build the workflow → Measure behavior → Iterate
理解任务 → 选择方案 → 构建应用流程 → 评测实际表现 → 持续迭代
```

I care about making AI systems understandable and improvable: define success before implementation, inspect failures at the right layer, and use evidence to guide the next change.

我重视 AI 系统的可理解与可改进：先定义成功标准，再定位问题发生在哪一层，并用评测证据决定下一步优化方向。

### 🧪 IN DESIGN / 项目构想 · AgentLens

**A reproducible evaluation and debugging workbench for tool-using LLM agents.**

为工具型 Agent 设计的可复现评测与调试工作台：记录运行轨迹，使用固定任务与模拟工具回放，并比较 Prompt/模型变化对任务完成、工具选择、参数正确性、答案依据、延迟与 token 成本的影响。

**Status:** Concept stage; no implementation or benchmark results are claimed yet.<br />
**状态：** 方案构想阶段，尚未声称已有实现或评测结果。
